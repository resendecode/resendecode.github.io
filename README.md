# resendecode.github.io

Site web personnel hébergé sur **GitHub Pages**, développé avec **Angular**.

## Description

Ce dépôt contient le code source du site personnel de resendecode, accessible publiquement via GitHub Pages. Il est construit avec Angular CLI v19.

## Technologies utilisées

- [Angular](https://angular.io/) v19
- HTML / CSS / TypeScript
- GitHub Pages

## Lancer le projet en local

```bash
cd resendecode.github.io
npm install
g serve
```

Le serveur de développement démarre sur `http://localhost:4200`.
